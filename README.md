# Upward Green Tree

A pixel-art endless climbing game. Guide a bouncing tree upward, land on color-coded platforms, collect gems and power-ups, avoid bad-luck effects, and take on random missions.

## Play locally

Open `index.html` in a modern web browser.

## Controls

- **Left / Right arrows** or **A / D** to steer.
- **P** or **Escape** to pause.
- On touch screens, tap the left or right side of the game to steer.
